# Official RealnessMC Content Pack

[!CAUTION]
The Mod is still in early Development! Many features are unfinished and might be broken!

## Disclaimer!
**This mod is ment for use on the RealnessMC Roleplay Server**

## Overview
This Mod adds many roleplay related Blocks, Items and Features
It also includes (Create mod style) Ponders to explain Features.

## Features
This is an Overview of all the Current Features! Planned Features are also included!

### Current
 - Ponder Implementation

### Planned
 - Many Decorative Blocks
 - Firefighter Gear
 - JEI, Create, Curios Impementation

## Compability
The Content Pack is made to be compatible with all other mods used in the modpack and many More!

### Implementations
The pack currently uses Ponder (Dependency)

In the Furure we will Implement JEI, Create and Curios.
Maybe we will also make other Mods compatible in the Furure!

## Dependencies
 - Ponder (Version: 1.0.81+mc1.21.1)
